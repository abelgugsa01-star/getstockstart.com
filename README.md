# getstockstart.com

Public marketing site for StockStart, served by GitHub Pages at
https://getstockstart.com. Static only. The product application lives in the
private StockStart repo and is deployed separately (planned: app.getstockstart.com).

The canonical copy of these pages is `public/website/` in the private repo;
legal pages are generated there by `scripts/build_legal_pages.py`. Edit
there, copy here, commit, push.
